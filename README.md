# CIFAR-10 Full-Stack AI Application

A high-performance, full-stack deep learning web application featuring a FastAPI inference backend (TensorFlow/Keras) and an SEO-friendly Next.js (App Router) frontend.

## Tech Stack

* **Backend:** FastAPI, Python, TensorFlow, `uv`
* **Frontend:** Next.js, React, Tailwind CSS, TypeScript, `pnpm`
* **Infrastructure:** Cloudflare Tunnels (for remote local testing)
